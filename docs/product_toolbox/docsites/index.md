# Doc-sites

Et doc-site er en hjemmeside til dokumentation. I OS2 kan projekter og produkter bruge doc-sites til at samle vejledninger, teknisk dokumentation og anden viden ét sted.

Her finder du praktiske vejledninger til at oprette, redigere og vedligeholde doc-sites med GitHub og VS Code.

Vejledningerne tager udgangspunkt i OS2's eksisterende løsninger og værktøjer.
