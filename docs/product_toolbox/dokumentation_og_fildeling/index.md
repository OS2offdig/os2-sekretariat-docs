# Dokumentation og fildeling

{: .warning }
DRAFT VERSION - NOT AN OFFICIALLY APPROVED DOCUMENT

Her finder du hjælp til at organisere, opbevare og dele dokumentation for OS2-produkter og -projekter.

Vælg en vejledning i sidemenuen for at komme i gang.

Dokumentation kan være fordelt på flere arkiver og platforme. Derfor har vi samlet vejledningerne her, så du lettere kan finde, organisere og dele dokumentation på tværs.

## Filarkiv og kodearkiv

OS2 anvender både Nextcloud og GitHub til opbevaring og deling af filer og dokumentation. Nextcloud rummer desuden lukkede arbejdsrum, hvor produkter og projekter kan samarbejde om interne dokumenter og materiale under udarbejdelse.

Det enkelte produkt eller projekt har ansvar for at organisere sin dokumentation. Derfor varierer det, hvordan arkiverne bruges, og hvor dokumentationen ligger.

**For at gøre det nemt at finde rundt skal der være en README i både det offentlige filarkiv og kodearkivet, som viser, hvad man finder hvor.**

Det er også god praksis at bruge README-filer i andre mapper, hvor de kan hjælpe med at skabe overblik.
