# Åbent filarkiv
{: .no_toc }

OS2's åbne filarkiv er et fælles sted, hvor produkter og projekter kan gøre dokumentation offentligt tilgængelig.

Filarkivet drives i Nextcloud, som OS2 også bruger til interne arbejdsområder med begrænset adgang.

Her finder du vejledninger til at bruge Nextcloud, dele filer og mapper samt administrere brugere og rettigheder.

[Åbn OS2's åbne filarkiv](https://boks.os2.eu/s/Di5cTQdSABd6ak4){: .btn .btn-outline }

{: .note }
> **Kært barn har mange navne**
>
> Internt i OS2 bruges flere betegnelser om filarkivet, fx "Boks.eu", "de offentlige mapper" og "Nextcloud".
>
> Bemærk, at Nextcloud er navnet på værktøjet og omfatter både det åbne filarkiv og interne arbejdsområder.
