# Åbent filarkiv
{: .no_toc }

OS2's åbne filarkiv er et fælles sted, hvor produkter og projekter kan gøre dokumentation offentligt tilgængelig.

Filarkivet administreres i Nextcloud, som også bruges til interne arbejdsrum, hvor arbejdsgrupper kan samarbejde om dokumenter med begrænset adgang.

Her finder du vejledninger til at bruge Nextcloud, dele dokumenter og administrere adgang.

[Åbn OS2's åbne filarkiv](https://boks.os2.eu/s/Di5cTQdSABd6ak4){: .btn .btn-outline }


{: .note }
> **Kært barn har mange navne**
>
> Internt i OS2 bruges flere betegnelser om filarkivet, fx "Boks.eu", "de offentlige mapper" og "Nextcloud".
>
> Nextcloud er det værktøj, OS2 bruger til både det åbne filarkiv og interne arbejdsområder. Det åbne filarkiv er den del, hvor dokumentationen er offentligt tilgængelig.
