## How to add a publication

1. Check that the publication may be shared and republished.
2. Save the file in `assets/knowledge-library/`.
3. Name the file using the format `year-publisher-short-title.pdf`.
4. Add a new row to the table above.
5. Include the publication title, a short description, publisher and year.
6. Link to the file using its path in the assets folder.
7. Check that the link works after publication.
