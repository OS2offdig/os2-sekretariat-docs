# Sådan er OS2 organiseret

OS2 er organiseret som en forening og et fællesskab af offentlige myndigheder, der samarbejder om udvikling, drift og videreudvikling af open source-løsninger.

Organiseringen kombinerer fælles rammer for foreningen med ansvar og beslutninger i de enkelte projekt- og produktfællesskaber.

## Foreningens organisering

| Aktør | Rolle |
|---|---|
| **Generalforsamlingen** | Foreningens øverste myndighed. Her vælger medlemmerne blandt andet OS2's bestyrelse. |
| **Bestyrelsen** | Har ansvar for foreningens overordnede retning, strategi og fælles rammer. |
| **OS2-sekretariatet** | Understøtter bestyrelsen, medlemmerne og projekt- og produktfællesskaberne med koordinering, rådgivning og fælles funktioner. |
| **Projekt- og produktfællesskaberne** | Samler de aktører, der samarbejder om udvikling, anvendelse og forvaltning af konkrete løsninger. |
| **Medlemmer og deltagende myndigheder** | Bidrager med behov, erfaringer, ressourcer og engagement i fællesskabet. |
| **Leverandører** | Bidrager blandt andet med udvikling, implementering, drift og support. |

OS2-sekretariatet er organisatorisk forankret i ITK i Aarhus Kommune, som blandt andet understøtter sekretariatets administrative funktioner.

## Roller i produktfællesskaberne

De enkelte OS2-produkter har deres egne fællesskaber og organisering inden for OS2's fælles rammer.

I et etableret produktfællesskab indgår typisk:

- **Styregruppen**, som har ansvar for produktets retning, økonomi og overordnede prioriteringer.
- **Koordinationsgruppen**, som bidrager med faglige behov, sparring og opfølgning inden for sit mandat.
- **Produktkoordinatoren**, som understøtter den daglige koordinering og fungerer som bindeled mellem styregruppen, koordinationsgruppen, leverandører og anvendere.
- **Anvendere og andre deltagere**, som bidrager med erfaringer, behov og viden om produktets anvendelse.

Roller og organisering kan variere afhængigt af produktets modenhed og behov.

## Samarbejde på tværs af OS2

OS2-sekretariatet bidrager til at skabe sammenhæng mellem foreningens fælles rammer og arbejdet i de enkelte fællesskaber.

Sekretariatet understøtter blandt andet videndeling, koordinering og samarbejde mellem medlemmer, produktfællesskaber, leverandører og andre aktører.

OS2 samarbejder desuden med offentlige organisationer, vidensmiljøer og nationale og internationale netværk om open source og offentlig digitalisering.
