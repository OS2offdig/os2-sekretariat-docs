# LinkedIn
{: .no_toc }

## Få noget delt på OS2's LinkedIn

Har du en historie, aktivitet eller nyhed, som kan være relevant på OS2's LinkedIn, så send den gerne til OS2-sekretariatet.

Sekretariatet producerer som udgangspunkt ikke opslag om det enkelte produkt fra bunden. Send derfor så vidt muligt:

- et forslag til tekst og de vigtigste oplysninger
- relevante links
- navn på personer eller organisationer, der bør tagges
- foto eller grafik, hvis det findes
- eventuelle ønsker til timing

Sekretariatet kan redigere og tilpasse materialet til OS2's kanal og vurderer, om og hvordan det passer ind i den øvrige kommunikation.
