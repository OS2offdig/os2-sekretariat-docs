# Open source i projekt- og produktarbejdet
{: .no_toc }

Open source er en central del af OS2's måde at udvikle og
forvalte digitale løsninger på.

For projekt- og produktfællesskaberne handler det blandt
andet om at gøre løsninger, dokumentation og viden
tilgængelige, så andre kan anvende, genbruge og bidrage
til udviklingen.

## Hvad betyder open source for et OS2-projekt eller -produkt?

OS2 bruger open source som metode til at understøtte
samarbejde, genbrug og fælles ejerskab.

I praksis handler det blandt andet om:

- **Åbne licenser:** Kildekode og dokumentation stilles til
  rådighed under relevante åbne licenser.
- **Dokumentation:** Andre skal kunne finde og forstå
  løsningen og dens udvikling.
- **Samarbejde:** Myndigheder, leverandører og andre
  bidragydere skal have mulighed for at bidrage til
  udviklingen inden for fællesskabets rammer.
- **Fælles forvaltning:** Produktets udvikling og
  prioriteringer forankres i produktfællesskabets organisering.

OS2's styringsmodel beskriver de krav, som projekter og
produkter skal efterleve afhængigt af deres modenhed.

## Licenser og governance-krav

OS2 anvender som udgangspunkt MPL 2.0 til kildekode og CC BY-SA 4.0 til dokumentation og øvrigt materiale, jf. OS2's vedtægter § 3.

OS2's governancerapport beskriver de krav, som projekter og produkter skal forholde sig til, herunder krav til licenser, dokumentation og åbenhed.

Du finder:

- [OS2's governancerapport](https://audit.os2.eu/docs/vurderingsgrundlag/governance_template.html) med gældende krav.
- [OS2's GitHub-organisation](https://github.com/OS2offdig) med repositories, kode, dokumentation og skabeloner.
