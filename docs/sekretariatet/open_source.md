# Open source i sekretariatets arbejde
{: .no_toc }

OS2 bruger open source som metode til at understøtte
samarbejde, genbrug, innovation og fælles ejerskab.

Sekretariatet bidrager til dette arbejde gennem rådgivning,
fælles rammer, værktøjer og videndeling på tværs af OS2.

## Hvordan understøtter sekretariatet open source?

Sekretariatet arbejder med open source på flere områder:

- **Governance og organisering:** Rådgivning om OS2's
  fælles rammer, roller og samarbejdsformer.
- **Licenser og rettigheder:** Vejledning om OS2's
  principper og fælles standarder.
- **IT-arkitektur og teknisk kvalitet:** Sparring om
  åbne standarder, dokumentation og tekniske løsninger.
- **Dokumentation og værktøjer:** Fælles vejledninger,
  skabeloner og platforme til samarbejde og videndeling.
- **Kommunikation og fællesskab:** Formidling af open source
  og understøttelse af samarbejdet på tværs af OS2.

Arbejdet tager udgangspunkt i OS2's vedtægter, vision,
mission og styringsmodel.

## Hvad er sekretariatets rolle i samarbejdet?

OS2's projekter og produkter udvikles og forvaltes gennem
fællesskaber af offentlige myndigheder.

Sekretariatet bidrager med rådgivning, koordinering
og fælles ressourcer, der understøtter fællesskabernes
arbejde og deres mulighed for at løfte opgaver selvstændigt.
