# Sekretariatet

<hr style="border: 0; border-top: 3px solid #3A7F3B; margin: 1.5rem 0;" aria-hidden="true">

**Hvad kan OS2-sekretariatet hjælpe med, og hvordan arbejder vi selv?**

I denne del af håndbogen finder du information om sekretariatets opgaver, ansvar og ydelser samt arbejdsgange og praktiske forhold for sekretariatets medarbejdere.

Du kan bruge siderne, når du skal afklare, hvad sekretariatet kan hjælpe med, hvordan en opgave bliver håndteret, eller hvor du finder information om sekretariatet som arbejdsplads.
