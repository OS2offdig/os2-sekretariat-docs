# Vedligeholdelse af fælles filer

{: .no_toc }

## Indholdsfortegnelse
{: .no_toc .text-delta }

1. TOC
{:toc}

Sekretariatet administrerer en række fælles filer i OS2's
offentlige filarkiv, eksempelvis produktlogoer og takstblade.

Nogle filer samles i fælles mapper, så alle produkter kan
henvise til den samme placering.

## Når filer samles eller flyttes

Sekretariatet sørger for at:

- [ ] Placere materialet i den relevante fælles mappe.
- [ ] Oprette eller opdatere README-filen i den fælles mappe.
- [ ] Opdatere links på de relevante sider, som sekretariatet administrerer.
- [ ] Orientere berørte produktfællesskaber om ændringen.
- [ ] Oplyse produktfællesskaberne om, at deres egne README-filer og eventuelle kopier skal opdateres.

## Produkternes egne mapper

Produktfællesskaberne har ansvar for at holde README-filer
og indhold i deres egne mapper opdateret.

Hvis en tidligere produktmappe ikke længere indeholder
originalmaterialet, skal dens README vise vej til den
fælles placering.
