# Onboarding af nye medarbejdere
{: .no_toc }


Nye medarbejdere introduceres gennem et forløb, der kombinerer ITK’s fælles onboarding med OS2’s egne introduktioner til værktøjer, produkter og governance.

## Administrativ onboarding – tjekliste

Denne tjekliste bruges ved opstart af nye medarbejdere i OS2-sekretariatet.

Den supplerer ITK's almindelige onboarding og skal sikre, at medarbejderen får de nødvendige adgange, værktøjer og informationer.

Ikke alle medarbejdere skal have adgang til alle systemer. Behovet afhænger af medarbejderens opgaver og ansvar.

### Før medarbejderen starter

- [ ] Afstem ITK's onboarding, herunder oprettelse af Aarhus Kommune-bruger og AZ-nummer (azXXXXX).
- [ ] Afklar, hvilke OS2-systemer medarbejderen skal have adgang til.
- [ ] Afklar behov for OS2-mailadresse og eventuelle fællespostkasser.
- [ ] Aftal, hvem der sørger for de forskellige oprettelser.

### Praktisk klargøring

- [ ] Bestil adgangskort til DOKK1.
- [ ] Bestil arbejdstelefon.
- [ ] Sørg for computer og tilhørende udstyr:
  - [ ] Skærm
  - [ ] Tastatur og mus
  - [ ] Headset/høretelefoner
  - [ ] Dockingstation og oplader
- [ ] Klargør arbejdsplads.
- [ ] Sammensæt en lille OS2-velkomstpakke med merch.

### Adgange og systemer

Opret eller tildel *relevante* adgange:

- [ ] **E-mail (One.com):** Personlig OS2-mailadresse, hvis relevant.
- [ ] **Hovedpostkassen:** Adgang til OS2's fællespostkasse.
- [ ] **Nextcloud (boks.os2.eu):** Bruger, relevante mapper og delingsrettigheder.
- [ ] **Airtable:** Adgang til OS2's CRM.
- [ ] **HeyLoyalty:** Brugeradgang, hvis medarbejderen skal arbejde med nyhedsbreve.
- [ ] **GitHub:** Adgang til relevante organisationer, repositories og opgaver.
- [ ] **Zulip/Authentik:** Adgang til OS2's interne kommunikation.
- [ ] **Outlook:** Adgang til OS2's fælles årshjul og relevante kalendere.
- [ ] **OS2's hjemmeside (Odoo):** Redaktøradgang, hvis relevant.
- [ ] **LinkedIn:** Administratoradgang til OS2's side, hvis relevant.

### Produktspecifikke adgange

Hvis medarbejderen skal arbejde med bestemte OS2-projekter eller -produkter:

- [ ] Afklar behov for adgang til produkternes fællespostkasser.
- [ ] Tildel relevante rettigheder til produktmapper i Nextcloud.
- [ ] Tildel adgang til relevante repositories og projektstyring.
- [ ] Afklar eventuelle administratorroller og særlige adgange.

### Registrering og introduktion

- [ ] Tilføj medarbejderen til sekretariatets medarbejderoversigt på os2.eu.
- [ ] Introducér OS2's fælles værktøjer og dokumentationsstruktur.
- [ ] Introducér håndbogen og relevante arbejdsgange.
- [ ] Gennemgå medarbejderens opgaver, ansvarsområder og samarbejdsrelationer.
- [ ] Kontrollér, at de nødvendige adgange fungerer.
- [ ] Invitér medarbejderen til kommende teammøder, stand-ups og øvrige faste møder i sekretariatet.

### Opfølgning

- [ ] Følg op på eventuelle manglende adgange.
- [ ] Registrér relevante adgange og administratorroller, så de kan gennemgås ved senere ændringer eller fratrædelse.
