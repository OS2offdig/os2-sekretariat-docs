# Introduktion
{: .no_toc }

<hr style="border: 0; border-top: 3px solid #3A7F3B; margin: 1.5rem 0;" aria-hidden="true">

**Hvad kan OS2-sekretariatet hjælpe med, og hvordan arbejder vi selv?**

OS2-sekretariatet understøtter foreningens arbejde og samarbejdet omkring OS2's projekter og produkter.

Denne del af håndbogen er både til dem, der samarbejder med sekretariatet, og til sekretariatets egne medarbejdere, som kan bruge den som en praktisk medarbejderhåndbog.

## Sekretariatets rolle i OS2

Sekretariatet understøtter OS2's bestyrelse, medlemmer og projekt- og produktfællesskaber.

Arbejdet omfatter blandt andet administration, koordinering, kommunikation og rådgivning om OS2's fælles rammer og arbejdsformer.

Sekretariatet bidrager til sammenhæng og videndeling på tværs af OS2 og understøtter samarbejdet mellem de forskellige aktører.

De enkelte projekter og produkter har deres egen organisering og ansvarsfordeling. Sekretariatets støtte afhænger derfor blandt andet af det konkrete samarbejde, de aftalte opgaver og de tilgængelige ressourcer.

## Sekretariatet som arbejdsplads

OS2-sekretariatet er organisatorisk forankret i ITK – Innovation, Teknologi og Kreativitet i Aarhus Kommune.

Sekretariatets medarbejdere er ansat i Aarhus Kommune og er omfattet af kommunens gældende rammer og retningslinjer for medarbejderforhold.

Sekretariatet har derudover egne arbejdsgange, værktøjer og samarbejdsformer, som understøtter arbejdet med OS2.

## Hvad kan du bruge siderne til?

### Samarbejder du med sekretariatet?

Her kan du blandt andet finde svar på:

- **Hvad kan sekretariatet hjælpe med?** Hvilken rådgivning og støtte kan du få til arbejdet med et OS2-projekt eller -produkt?
- **Hvem har ansvar for hvad?** Hvordan fordeles opgaverne mellem sekretariatet og projekt- eller produktfællesskabet?
- **Hvordan samarbejder vi?** Hvad varetager sekretariatet, og hvordan koordineres fælles opgaver?

### Arbejder du i sekretariatet?

Her kan du blandt andet finde svar på:

- **Hvordan løser vi vores fælles opgaver?** Fx økonomi, fakturahåndtering, administration og samarbejde med produktfællesskaberne.
- **Hvilke arbejdsgange og rutiner bruger vi?** Hvordan håndterer vi tilbagevendende opgaver og sikrer, at viden og ansvar bliver overdraget?
- **Hvad gælder for mig som medarbejder?** Hvor finder jeg information om arbejdsforhold, udstyr og praktiske forhold?
- **Hvilke funktioner findes i sekretariatet?** Hvor finder jeg funktionsbeskrivelser og oplysninger om ansvarsområder?
